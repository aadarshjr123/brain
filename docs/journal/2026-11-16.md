# 2026-11-16 — Kickoff

**Moved:** Idea → two mockups → agreed design (v3 canvas graph). PRD, system design, roadmap, backlog, process and ADR-0001..0007 written.

**Decisions:** Next.js over SPA (ADR-0002), Canvas 2D over SVG/Three (ADR-0003), content in repo (ADR-0004), no accounts (ADR-0005), Redux + Zustand split (ADR-0006), monorepo (ADR-0007).

**Problems hit:**
- First mockup (action list + SVG trace) missed the mental model Aadarsh wanted: a map you walk, not a list you click. Learning: prototype the *interaction*, not the content, first.
- Force graph felt congested at 144 nodes. Fixed with stronger repulsion, longer links, collision padding and label gating by zoom. Learning: label policy matters more than node count.
- Zustand + Redux + TanStack Query were all requested. Resolved by giving each a disjoint job and deferring TanStack until a server exists.

**Learned:** Removing login simplified three sections of the system design and removed two vendors. Scope removal is a design tool.
